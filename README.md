# ZeroTwo for Windows

ZeroTwo builds and changes Power BI reports with an AI agent. You say what you want, in your own words; the agent does the work in Power BI Desktop, in the background; you review every change beside the report and keep it or undo it.

This repository holds the **installers and release notes**. The source code is not public.

## Download

**[Download the latest installer (ZeroTwo-Setup.exe)](https://github.com/akoppcode/zerotwo-releases/releases/latest/download/ZeroTwo-Setup.exe)**

All versions: [Releases](https://github.com/akoppcode/zerotwo-releases/releases)

## Requirements

- Windows 10 or 11 (x64)
- Power BI Desktop, current version
- Access to Claude (Anthropic) or ChatGPT (OpenAI)
- A ZeroTwo licence key. Work at Orkla? Get yours at [zerotwo.no](https://zerotwo.no)

## Install

1. Run `ZeroTwo-Setup.exe`. It installs for the current user; no admin rights needed. Windows may ask you to confirm an app from a new publisher.
2. On first start ZeroTwo checks what it needs: Power BI Desktop, your sign-in and your agent. Anything missing gets a link and a one-line explanation.
3. Paste your licence key, pick Claude or ChatGPT, and open a `.pbip` project. Or take the five-minute product tour first.
